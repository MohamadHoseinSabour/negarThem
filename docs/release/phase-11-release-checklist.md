## ۱. رفع خطاهای امنیتی و اعتبارسنجی پشتیبان‌گیری (Step 1 — Backup Import Defect Fixes)

- [x] **رفع نقص A (Sanitization تابعی مستقل بدون وابستگی به Tab):**
  - افزودن تابع `negar_theme_sanitize_full_settings($submitted, $base_settings)` در `inc/theme-settings.php` جهت اعتبارسنجی یکپارچه تمامی گروه‌ها (`branding`, `texts`, `layout`, `products`, `colors`, `typography`, `header`, `contact`, `footer`, `social`) بدون اتکا به مقدار `$_POST['negar_theme_settings_tab']`.
  - اصلاح متد ضدعفونی‌سازی در `negar_theme_backup_supported_groups()` برای گروه `NEGAR_THEME_SETTINGS_OPTION` به تابع اعتبارسنجی کامل.
  - به‌روزرسانی تابع اصلی `negar_theme_sanitize_settings()` به‌گونه‌ای که در صورت فقدان تب ارسالی (عملیات درون‌ریزی پشتیبان یا به‌روزرسانی برنامه‌نویسی‌شده)، به‌جای بازگرداندن داده‌های فعلی پایگاه داده و از دست رفتن تنظیمات وارداتی، متد `negar_theme_sanitize_full_settings()` فراخوانی شود.
- [x] **رفع نقص B (تصحیح ساختار اسکیما و ارجاعات در `inc/theme-backup.php`):**
  - **پکیج‌های محصولات (`NEGAR_THEME_PRODUCT_PACK_OPTION`):** بررسی عمیق ساختار `$clean['packs'][$pack_id][$slot_id]` و صفر کردن شناسه‌های ناموجود یا غیرفعال در فروشگاه با ثبت هشدار صریح برای مدیر.
  - **استوری‌ها (`NEGAR_THEME_STORY_OPTION`):** اصلاح اسکیما به کلید `stories` و فیلدهای اختصاصی (`thumbnail_id`, `image_id`, `video_id`, `poster_id`, `product_id`)، اعتبارسنجی نوع رسانه با mime type و بررسی انتشار محصول در کاتالوگ فروشگاه.
  - **برندها (`NEGAR_THEME_BRAND_OPTION`):** اصلاح اسکیما به کلید `brands` با فیلدهای `term_id`, `enabled`, `logo_override_id`، بررسی وجود ترم در تاکسونومی `product_brand` و اعتبارسنجی تصویر لوگوی جایگزین.
- [x] **آزمون دور رفت‌وبرگشت واقعی (Real E2E Backup Round-Trip):**
  - تهیه اسنپ‌شات از پایگاه داده -> مقداردهی آزمایشی با مقادیر متمایز -> صدور خروجی JSON -> جهش عمدی تنظیمات دیتابیس -> بررسی پیش‌نمایش (تایید ۰ تغییر در دیتابیس) -> اعمال ایمن پشتیبان -> تایید بازیابی ۱۰۰٪ مقادیر اولیه -> آزمون رول‌بک در زمان خطا -> بازگردانی وضعیت اولیه.
